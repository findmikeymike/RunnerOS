## How this differs from `docs/backlog/`

- **`docs/backlog/`** — V1 work that is started or committed to and not finished.
- **`docs/v2/`** — work consciously ruled out of V1. Nothing here is owed.

If something here becomes V1, promote it to a real spec in the folder that owns
the feature and delete the note.
