# T-06A — durable pause, resume and cancellation

Revision r4 · P-03 first slice · executable · user authorized commit and continuation on 2026-09-09.

Build the control prerequisite before approval/effect adapters. A host-only command carries workspace/run identity, a unique command ID and expected entity version. Save command receipt and state/event/outbox transition together; identical duplicates return the original receipt without reapplying intent. Conflicts fail explicitly.

Persist a control revision independent of ownership epoch. Pause/Resume/Cancel invalidates successor dispatch from an older execution. A dispatched model/read result may still commit under its original live ownership while paused/cancelled, without changing that control state. Explicit Resume drains the old execution and obtains a new claim before replaying immutable results. Unchanged payload, credentials, runtime manifest, budgets and deadlines remain required.

Pause is cooperative: it prevents new model/tool dispatch permits and completion at the next journal checkpoint. It does not undo a permit already committed before Pause, terminate an in-flight provider request, or promise rollback of external effects. Writable adapters remain disabled. Model/tool results issued before control changes can be retained, but new successors cannot use an obsolete control revision. Cancel persists before transport abort.

Own journal/schema/protocol in one task owner; host service/tests in a second bounded owner; independent process fixtures in a third. Schema advances to 2 with transactional creation of command storage; the durable adapter revision advances to pi-readonly-2. Prior schema data stays readable; unsupported prior adapter runs cannot resume automatically. This is not the P-05 migration/downgrade rollout.

Verify command receipt rollback, duplicate/stale/cross-workspace commands, pause/resume race, late errors/results, failed cancellation persistence, owner fencing, explicit resume after SIGKILL, real native-read result reuse and packaged journal persistence. Independently rival-review and fix all meaningful findings. T-06 approvals/steering, T-07 effects/live proof and T-08 children remain outstanding; T-06A acceptance does not close P-03.
