## Outcome and steps

1. In a disposable config root implement the minimum run/operation/wait/child/outbox/epoch records needed by the proof. Use the chosen supported SQLite binding; no production schema commitment yet.
2. Verify WAL/FULL/foreign keys/schema version/file permissions and bounded busy handling in both test runtime and the real packaged Electron main process. Record binary path/version and config root; never point the prototype at the user's `.artist-os` data.
3. Implement atomic admission + initial outbox, completed-result + next-continuation, claim compare-and-set with epoch, and duplicate command handling. Use deterministic barrier hooks controlled by the external test supervisor.
4. Kill the writer before/after commit, run two contenders, inject disk-write failure/lock contention and open a newer schema. Inspect persistent rows with a fresh process. Store never silently becomes empty or volatile.
5. Back up consistently and restore into another disposable root with dispatch disabled. Verify required artifact references and permissions. Do not call a process-kill test physical power-loss certification.
6. Record D-02 binding/path and candidate performance/packaging results in `evidence/T-02-storage.md`. If the supported binding fails, record the failure and bounded alternative; do not quietly swap runtimes for a passing demonstration.
