# T-04 — production journal, protected payloads and host service

Revision r3 · P-02 · executable · user-authorized 2026-09-09.

Own new shared/durable-execution journal and secure key boundary. Production implementation must not import P-01 fixtures. Keep v2 data in a private config-root directory distinct from legacy WORKFLOW run discovery. Versioned encrypted state + transactional events/outbox, stable run/turn/call identities, ownership epochs, persistent deadlines/model attempts/cost reservations, commands, read-only projections. Key loss/storage failures fail closed; backup is quarantined before publication.

First route deliberately supports one sequential agent step with Pi certified local reads (read/grep/find/ls); reject other capabilities/step completion side effects at admission. Model route, account, prompt/context, tool manifest and runtime version are pinned. No public enabling or paid tests; live provider certification remains later. Scope is a real journal/bridge integration, not a second workflow language.

P-02 eligibility is deliberately explicit: existing manual workflows with one literal agent-step input, no template expansion, retries, custom output/schema/task-mode obligations, or output publishing. A host-resolved agent persona and selected workflow snapshot are frozen. Default nonempty final-output requirement is enforced before the complete checkpoint. Unsupported semantics fail admission rather than silently disappearing.

Credential identity uses a digest of the exact API-key/bearer transport, checked again at actual Pi dispatch. Rotating that credential requires a new run; native OAuth refresh, IAM and ambient credentials are unsupported in this first route. A later stable-principal/grant adapter may relax this only with evidence. Persisted SDK/adapter manifest drift also fails closed.

Validation: journal unit/fault cases, wrong key/corruption/storage/full/backup, race/owner/fence, duplicate/cross-workspace commands, immutable cached responses and changed context rejection. Real SDK separate-process recovery tests and packaged Electron probe consume this implementation. Production key envelope uses OS safeStorage, no hardware fallback; tests may inject explicit test protection. Preserve other agents' work.
