# T-06B — exact durable approvals

Revision r5 · P-03 approval slice · executable · user authorized commit and continuation.

Use the accepted command/fence layer to persist a real tool wait at the existing internal Pi execution boundary. A trusted host permission resolver declares whether the exact normalized tool request is already allowed or requires a decision. Ordinary authorized reads do not gain artificial approval prompts. The new internal resolver is opt-in; public escalation UI/RPC routing is not enabled here.

Bind a decision to run/workspace, stable operation/approval identity, normalized input digest, approving principal, current policy revision, exact credential identity and expiry. Store pending wait before returning the blocked checkpoint. Decision intake uses command ID and expected version; duplicate historical decisions never undo newer Pause/Cancel. Consume a valid approval and persist its tool dispatch attempt in one transaction. Repeat attempts must retain the same operation and satisfy current authorization, expiry and budgets.

Every actual tool dispatch re-resolves current permission. Policy/account/principal drift cannot reuse an old grant. Expiry remains a saved outcome; explicit Resume may request reauthorization of an expired wait, but cannot bypass a pending decision. Approval while paused stays paused. Denial/cancellation blocks successors; late observations cannot revive execution.

Single owner edits journal and approval tests; separate owner edits host integration/tests. Primary owner controls shared protocol and real host process probes. Runtime manifest advances to pi-readonly-3; no automatic execution of older adapters. Approvals remain limited to certified local read tools in this slice; writes/effects and child delegates stay disabled.

Validation: wrong digest/actor/policy/account, stale/conflicting/duplicate decisions, expiry, permission revocation, pause/approve and cancel/approve races, atomic consume/dispatch rollback, and actual host/factory/Pi/native-read recovery after SIGKILL while waiting and after decision commit. Revalidate policy after decision before dispatch. Run independent rival review, fix meaningful defects and record precise evidence. Ordered steering remains the next T-06 slice; do not close all of T-06/P-03 based on this approval slice.
