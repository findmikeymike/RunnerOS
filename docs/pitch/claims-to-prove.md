# Claims To Prove

These are strong pitch claims worth using only after we have the right demo, screenshot, test, or public proof.

## Model Flexibility

Claim:

```text
Use the models and providers you want instead of being locked into one AI company.
```

Proof needed:

- connection settings screenshots
- supported provider list
- clear explanation of what is currently supported

## Specialist Agent Depth

Claim:

```text
Artist OS Desktop ships with specialist workers for the real jobs around music.
```

Proof needed:

- worker library screenshots
- examples of Content Genius, Art Director, Ads Agent, Social Publisher, Outreach, and Video workflows
- output examples

## Video System Strength

Raw user angle:

```text
The video agent system alone competes with tools like Higgsfield and could justify the app.
```

Safer public version until proven:

```text
Artist OS Desktop includes serious video and motion workers for clips, edits, captions, previews, and render-ready assets.
```

Proof needed:

- finished clip demos
- side-by-side workflow demo
- render receipts
- source-to-output walkthrough

## Art Direction Taste

Claim:

```text
The art agents understand aesthetic, culture, references, layout, and artist taste.
```

Proof needed:

- single art examples
- reference-board examples
- prompt/output comparison
- before/after visual direction

## Living Intelligence

Claim:

```text
The system gets smarter as it learns the artist, brand, voice, campaign, audience, and approved work.
```

Proof needed:

- Shared Intel demo
- State of Play demo
- Finals demo
- worker launched with prior context

## Human Layer

Claim:

```text
One-click access to real music promo and expert-review paths.
```

Safer public version until fully wired:

```text
Artist OS Desktop can prepare clean handoff packets for playlisting, influencer, IG trending, and expert song-review workflows.
```

Proof needed:

- actual handoff packet demo
- partner/provider flow screenshots
- exact wording around what is inquiry, draft, send, or booked

## Multi-Profile Social Operations

Claim:

```text
Agents can help post, reply, comment, and answer DMs across multiple accounts or profiles per platform.
```

Safer public version until fully verified:

```text
Artist OS Desktop can prepare approval packets for posting, replies, comments, and DMs across multiple social profiles, then execute supported actions once approved.
```

Proof needed:

- connected social profile selector demo
- approval packet showing exact account/profile and action
- dry-run plan
- execution receipt
- clear list of which platforms/actions are currently supported
