# Human Layer

## Core Idea

Artist OS Desktop should not pretend every problem is solved by another AI response.

Some music career moments need real humans:

- playlisting
- influencer campaigns
- IG music trending campaigns
- producer and writer feedback
- expert song vetting
- future vetted creative or promo partners

## Current Pitchable Shape

Artist OS Desktop can help package the artist, song, campaign, assets, goals, and missing info into a clean handoff.

Examples:

- draft an inquiry for a playlisting provider
- draft an inquiry for an IG music trending provider
- draft an influencer campaign inquiry
- prepare a Record Doctor submission packet for expert song review

## The Promise

The app does not just generate ideas.

It helps move work from:

```text
idea -> campaign brief -> asset packet -> approval -> human/vendor handoff
```

## Copy Angle

```text
When the next best move needs a real person, Artist OS Desktop helps you package the work and make the handoff clean.
```

## Honesty Note

Be precise in public copy.

If a workflow creates an inquiry or handoff packet, say that. Do not imply a fully automated marketplace, guaranteed placement, guaranteed campaign outcome, or direct booking flow unless that exists and is verified.
