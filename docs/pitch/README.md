# Artist OS Desktop Pitch

Working name: **Artist OS Desktop**.

Name is not locked. Use this as the pitch workspace until naming is final.

## Core Position

Artist OS Desktop is a music artist command center.

It gives artists and managers an AI-powered operating desk for release strategy, content, visuals, outreach, ads, socials, merch, approvals, and campaign execution.

It is not generic AI chat. It is a music-specific work system with specialist agents, shared artist context, durable outputs, campaign kits, and approval gates.

## One-Line Pitch

Artist OS Desktop is an AI command center for music artists and managers, with specialist agents that understand the artist, manage campaign work, create assets, coordinate promotion, and turn messy creative output into approved release-ready materials.

## Short Pitch

Most artists are trying to run a career from scattered chats, notes, folders, dashboards, and DMs.

Artist OS Desktop gives them one place where the artist profile, brand, voice, campaign world, assets, agents, tools, outputs, approvals, and next moves stay connected.

The result is closer to having a lightweight management team inside the app than having another chatbot tab open.

## Landing Page Must-Sell Ideas

- Built-in artist team: an expandable directory of every included worker.
- Campaign workspaces: one release, one organized command center.
- Outputs -> Finals: messy exploration becomes approved campaign assets.
- Vault: masters, art, lyrics, press photos, clips, references, and brand assets made usable by agents.
- State of Play: the app tells the artist or manager what matters next.
- Social operations: agents can prepare and execute approved posts, comment replies, and DMs across multiple social profiles.
- Approval control: agents prepare real work, but risky external actions stay user-approved.
- Proof gallery: show real examples, not abstract feature claims.
- Founder posture: built by an artist, not an enterprise software committee.
