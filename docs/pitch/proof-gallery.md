# Proof Gallery

## Purpose

The pitch should show what Artist OS Desktop produces.

Avoid abstract "AI productivity" claims. Show concrete artist and manager artifacts.

## Must-Have Proof Tiles

### Campaign Kit

Shows:

- campaign brief
- release world
- final cover art
- final captions
- final press copy
- final clips
- next move

### Caption Pack

Shows:

- platform
- hook
- on-screen text
- caption
- posting note
- approval state

### Art Direction Board

Shows:

- visual lane
- references
- typography direction
- color/taste rules
- single-art prompt
- anti-generic notes

### Ad Plan

Shows:

- artist DNA signal
- campaign objective
- target audiences and territories
- creative angles and copy lanes
- budget logic
- setup or browser-draft plan
- risk notes
- approval-ready next action

### Outreach Packet

Shows:

- target person
- fit rationale
- source links
- outreach angle
- subject lines
- email draft

### Content Calendar

Shows:

- week view
- post ideas
- asset needs
- worker owner
- approval status

### Video / Motion Receipt

Shows:

- source assets
- edit/render path
- preview
- format
- caption treatment
- export receipt

### State Of Play

Shows:

- what is happening
- what is blocked
- what needs approval
- what is ready
- recommended next move
- suggested worker

### Built-In Artist Team

Shows:

- dropdown categories
- worker names
- one-line jobs
- example outputs

## Proof Rule

Every public proof tile should answer:

```text
What did the app help the artist or manager actually move forward?
```

If the tile only shows a chat answer, it is not strong enough.
