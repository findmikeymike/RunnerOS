# Creator Operations Foundations Completed

This records implementation work that is no longer a feature-construction backlog. Remaining live-account, packaged-app, multi-machine, and release-proof work stays in `docs/backlog/TO-DO.md` and `docs/backlog/external-integration-live-verification.md`.

## Calendar And Scheduled Work

- Separate HQ and Campaign Calendar pages with contextual day actions and selectable item markers.
- Progressive Event, Agent Task, and Workflow Run composition without one oversized modal.
- Typed Scheduled Work shared by Calendar and Automations, including optional hidden Calendar display.
- Backend-owned mutations, ownership validation, restart recovery, idempotency, chains, required Outputs, review states, and guarded social execution receipts.
- HNIC-only typed scheduling tools and campaign release-day Calendar highlights.

## Social Publishing

- Social Publisher can execute explicitly authorized, bounded comment and DM reply mandates using Artist Voice examples and exact account/thread targeting.
- TryPost and Postiz have built-in provider agents, managed source connections, media-aware/schema-first contracts, approval boundaries, migrations, and receipt requirements.
- Keys/Settings exposes provider-agent connection cards and tests real source credential/tool readiness without exposing secrets.

## Product Intelligence

- YouTube Intelligence has preloaded trusted channels, newest-unseen-upload filtering, transcript packets/cache, required HQ report Outputs, categorized Shared Intel nuggets, weekly scheduling, toggle, and manual run.
- Spotify Analyst uses the authenticated browser source for snapshots, deltas, and anomaly handoffs.
- Spotify Playlist Creator has evidence-based strategy, bounded cached track discovery, account verification, approval contracts, creation flow, and receipt shape.
