# User Guide

These docs explain RunnerOS for normal users, not developers.

- [Core Surfaces](./01-core-surfaces.md): the everyday buttons, pages, workers, skills, outputs, workflows, and automations.
- [Advanced Abilities](./02-advanced-abilities.md): background workers, worker-to-worker messaging, shared intel, memory, permissions, and long-running work.
- [Service Keys](./03-service-keys.md): which outside accounts/API keys are needed for richer workers and where to get them.

The simple rule:

Use **HNIC** when you do not know where to start. Use **Workers** when you know the job. Use **Outputs** when you want to find finished work.
