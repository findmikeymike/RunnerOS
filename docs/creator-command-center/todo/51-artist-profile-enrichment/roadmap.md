# Roadmap

Three phases. Graph/status authority: plan.json. The dependency backbone is P1 → P2 → P3; no duration estimate or critical-path claim is made.

## P1 — Prove one complete enrichment

T01 (executable): typed data, identity, overrides, publication rules and failure fixtures.
T02 (executable): existing Deep Research adapter + minimal Profile panel + Manager career retrieval, first real source-to-save-to-agent slice.

Entry: implementation instruction exists; read current baseline and confirm storage/source contracts. Exit: one identified artist produces supported stored facts, Profile prose remains unchanged, Manager can retrieve them, and a Spotify request counter stays zero. A synthetic fixture is mandatory; a live public-source slice is required before expanding research breadth. Read-only search does not need a new plan approval. Existing source availability is checked by S01; the entry review is an engineering check.

## P2 — Complete the everyday experience

T03 (outlined): correction/removal/Undo, refresh, interruptions, conflict merge and identity switching, full section states and accessibility.
T04 (outlined): consistent Manager brief/shared launch/campaign focus consumption and cache invalidation, relevant recipe updates preserving customization.

Both depend on P1; T03 owns UI/service mutation code, T04 owns agent context/brief integration. Their data contract is frozen by T01; coordinate one integration owner for shared type changes. Neither may silently change the schema. Exit: A06–A11 pass across UI and backend; user control survives rephrasing/retry and an already-running session gets current context on its next turn.

## P3 — Prove and land

T05 (outlined): adversarial/system tests and source-quality evaluation covering exact identity, unsupported evidence, prompt injection, stale callbacks, storage failure, Team conflicts and snapshot nonduplication.
T06 (outlined): canonical disposable/live acceptance, documentation and rollout; preserve normal profile/analytics behavior and record actual remaining provider/visual limitations.

Exit: passing regressions, all type checks and dependency containment, independent review, real source-to-profile-to-Manager evidence, canonical UI evidence. No mock/stub/plan checker counts as live proof. Follow user's existing commit-after-job workflow, catch up with main, verify after merge, then land/push. No recurring permission checks at phase boundaries. App restart remains separately authorized under standing instructions.

Rollback: disable new entry points; retain the separate research document. Do not rewrite original profile, delete Pulse data, or reset corrections. If P1 disproves the chosen source's safe retrieval/receipt contract, adjust the adapter within existing infrastructure before expanding P2; do not build a new general research platform.
